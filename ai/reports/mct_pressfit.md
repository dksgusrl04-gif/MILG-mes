# MCT + 압입 — 따로 만든 모델 vs 합친 모델

같은 조건: 묶음(공구 · 작업일 · 스냅 종류)을 통째로 빼고 학습 → 뺀 묶음으로 평가 · 입력 = 센서만 · 값 = 위험도 상위 10% 알림 안의 불량 비율 (AUC).
따로 = 그 데이터만 · 같은 공정 합침 = 같은 공정의 다른 데이터까지 · MCT + 압입 합침 = 두 공정 전부 한 모델 (데이터별 보정).
