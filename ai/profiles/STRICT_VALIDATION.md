# 3분할 공구·설비·압입 평가

PowerShell에서 실행:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\dksgu\Desktop\code\mlng-mes\mlng-mes\tools\Validate-MilgProcesses.ps1"
```

기본 압입 입력은 원본 앞 100,000행입니다. 개입 없는 관측 행만 사용합니다. 배치를 60/20/20%로 나눠 학습/검증/시험으로 배정합니다. `-MaxRows`는 별도의 새 실험에서만 변경하고 결과 선택 기준을 시험 수치에 맞춰 반복 조정하지 마세요. `-TargetFpr 0.05`는 검증 정상 작업에서 목표로 하는 알림률이며 현장의 오경보율 보장이 아닙니다. `-Quick`은 MCT HMoTP만 평가하고 나머지 MCT·설비 시험은 생략합니다.

MCT는 HMoTP·NASA·Stiehl 각각 공구 하나를 시험으로 제외하고 남은 공구를 학습/검증으로 나눕니다. Stiehl은 설비 하나를 제외하는 시험도 추가합니다. 설비가 3대뿐이므로 각 설비 시험에서 1대는 학습, 1대는 검증, 1대는 시험에 사용합니다. 결과 불확실성이 크며 현장 일반화를 확정할 수 없습니다.

현재 운영 모델이 사용한 schema/누설 검사/누적 정규화 설정을 재사용하면 시험 정답이 표현 선택에 관여할 가능성을 점검하기 어렵습니다. 그래서 이번 강화 평가는 고정된 센서 칼럼 목록과 학습 구간에서만 학습한 결측 대체·평균·표준편차를 사용합니다. 시험 정답은 후보 학습·임계값 선택 함수의 인자로 받지 않습니다. 시험 데이터 통계도 정규화에 사용하지 않습니다. 모델은 기존 누적 통계 모델을 동일한 방식으로 초기화해 재학습합니다.

이는 기존 운영 전처리의 검증 완료 선언이 아니라, 정답 참조를 제거한 별도 기준 실험입니다. 기존 운영 특징과 학습 표현이 달라 이전 교차검증 수치와 직접 비교하면 안 됩니다. 이번 실험의 운영 승격은 자동으로 수행하지 않습니다. 저장된 기존 모델도 수정하지 않습니다.

출력: `ai/reports/strict-validation/<시각>/report.json`과 `report.md`. JSON에는 각 분할의 그룹, 학습 전처리, 검증 임계값과 후보 선택, 시험 혼동행렬·AUC·검출률·오경보율이 들어갑니다. 반복 교차검증의 통합 AUC는 서로 다른 모델 점수를 합쳐 계산하지 않고 그룹별 AUC 평균으로 제공합니다.

압입 비교:
- 학습 통계 모델
- 학습 정상 기준 이탈 규칙
- 검증에서 임계값을 정한 규격 대비 이탈 규칙
- 사전에 고정된 공학적 규격 판정 (허용 범위 외이면 불합격)

모든 `MpGood`, `ProcessResult`, ID, 개입 정보는 예측 특징에서 제외합니다. `ProcessResult`는 시험 채점용 정답으로만 사용하고 ID는 분할용으로만 사용합니다. 규격 판정은 실제 센서 측정값과 LTL/UTL로 직접 계산합니다. 시뮬레이터의 원래 합격 플래그를 그대로 예측값으로 사용하는 방식이 아닙니다.

실행 확인: 2026-11-06, CausalMan 앞 100,000행 및 보유 MCT 3종. 압입 고정 규격은 해당 시험에서 검출률 100%, 오경보 0%; 학습 모델은 검출률 60.82%, 오경보 7.73%였습니다. 합성 정답 규칙을 재현하는 과제에서는 신경망/통계 모델 추가가 필요하다는 근거가 없습니다. 다른 과제(사전 이상, 실제 불량, 규격 내 잠재 불량)의 성능으로 해석하면 안 됩니다.

관련 회귀 검사: 학습 전처리 동결, 검증 전용 임계값, 그룹 분할 비중첩, 시험 정답을 받지 않는 후보 선택 함수. 데이터는 이미 이전 실험에서 확인했으므로 새로운 블라인드 검증은 아닙니다.
