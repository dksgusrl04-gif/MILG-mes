# MILG 회사 홈페이지

저장소 루트 `index.html`은 회사 홈페이지이며, 기존 MES는 `web/`에서 제공합니다. GitHub Pages의 저장소 루트 배포를 그대로 사용할 수 있습니다. 별도 빌드나 외부 폰트/CDN 의존성이 없습니다.

- `site.css`, `site.js`: 반응형 화면, 모바일 메뉴, 데모 모달, 문의 메일 초안 및 검토서 다운로드.
- `demo/index.html`: 합성 데이터 기반 위젯 UI 체험. 실제 AI 추론·MES API를 호출하지 않습니다. 조치 이력은 방문자의 브라우저에만 저장됩니다.
- `assets/manufacturing.webp`: MILG를 위해 AI로 생성한 기업 콘셉트 이미지. 보유 설비나 고객 현장 사진이 아닙니다.
- `assets/product.webp`: 실제 HTML 프로토타입을 브라우저에서 캡처한 화면.
- 문의 주소: `MILGAICEO@gmail.com`. 폼은 메일 앱을 열며 자동 전송이나 서버 저장을 하지 않습니다. 메일 앱 미설정 시 TXT 검토서를 다운로드할 수 있습니다.
- 기업별 독립 학습·사내 배포는 목표 구조로 표시합니다. 고객 실증 성과나 고객사 로고를 가정하지 않습니다.

로컬 확인: 저장소 루트에서 `python -m http.server 8767 --bind 127.0.0.1` 후 `http://127.0.0.1:8767/` 접속. 메일 수신 주소 변경 시 루트 HTML과 `site.js`를 함께 수정합니다.

검증: Edge에서 390/768/1024/1440px 가로 넘침, 메뉴, 데모 LOT 전환, TXT 다운로드 확인. MES 데이터 로딩이 늦을 때의 초기 렌더링 오류를 `web/js/core.js`에서 방지하고 기존 단위·타입·스탬프·E2E 검사 완료.
